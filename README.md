# 引经据典 · 给大白话配一句经文

> 你说一句人话，它从四万两千条经典里翻出一句对得上的，甩回给你。

比如你在群里说 **「你们中出了一个叛徒g」**，它回：

> 「我不是拣选了你们十二个门徒吗？但你们中间有一个是魔鬼。」
> ——《约翰福音》6:70

说 **「我只有两岁g」**：

> 「耶和华我的神啊，如今你使仆人接续我父亲大卫作王；但我是幼童，不知道应当怎样出入。」
> ——《列王纪上》3:7

末尾那个 `g` 是暗号（guwen / gao）。不带 `g` 它不会自作多情去查书，就当普通聊天。

---

## 它凭什么找得到

不联网、不调大模型、不烧 token。本地一个 42940 条的语料库 + BM25 打分。

- **语料**：圣经和合本（66 卷 1189 章 31101 节）+ 论语、孟子、大学、中庸、诗经、唐诗三百首、古文观止、幽梦影、增广贤文、朱子家训、弟子规、三字经、千字文、幼学琼林、声律启蒙
- **切词**：jieba 分词 + 单字 + bigram，繁转简（opencc），所以「樂子之無知」也能被「无知」搜到
- **打分**：BM25（k1=1.5, b=0.75），再按词覆盖度过滤

```bash
cd scripts
python3 quote.py "你在这里做什么" -n 12
python3 quote.py "信 诺 言 诚" -n 12          # 大白话搜不到就拆成文言词
python3 quote.py "谁没有罪" --book 圣经 -n 5
```

大白话直搜经常抓瞎，所以真正的用法是**先整句搜、搜不到再拆词**。比如「说话要算数」拆成 `信 诺 言 诚`，「不想干了」拆成 `劳 苦 倦 己`。

## 一条硬规矩

**只输出库里真实存在的句子。** 查不到就说没有，不许凭记忆补一句《论语》——它干过这事，被骂了，所以写进了 SKILL.md 第一条。

## 踩过的坑（留着警醒后人）

- 《大学》《中庸》在 chinese-poetry 里是 dict 不是 list，第一版索引直接崩
- 圣经正文里混着 `<e>` `<br/>` 标签，一开始全被当成词切进去了
- 只用字面匹配抓不到「脱开原句」的语义，所以才有了「拆词」这一步
